# Miraath International — Website v2

Premium React + Vite corporate website for **Miraath International**.

## Stack
- React + Vite
- Tailwind CSS
- Framer Motion
- lucide-react

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Version
Current release: **v2.0.0**
